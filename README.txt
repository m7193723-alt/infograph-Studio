INFOGRAPH STUDIO — стартовый сайт
================================

Файлы:
- index.html — структура и текст сайта
- style.css — оформление и адаптация под телефон
- script.js — мобильное меню и автоматический год

КАК ОТКРЫТЬ:
1. Распакуй архив в отдельную папку.
2. Открой папку в Visual Studio Code.
3. Открой index.html в браузере (можно установить расширение Live Server в VS Code).
4. Изменяй тексты и контакты прямо в index.html.

ОБЯЗАТЕЛЬНО ПЕРЕД ПУБЛИКАЦИЕЙ:
1. В index.html найди https://t.me/your_telegram и замени на свою настоящую ссылку Telegram.
2. Замени hello@infograph-studio.ru на рабочую почту, если она есть.
3. Добавь реальные работы вместо демонстрационных концептов или оставь пометку, что это концепты.
4. Проверь все тексты, ссылки и отображение на телефоне.

ВАЖНО:
Форма заявки пока не подключена — это демонстрационный первый релиз без сервера.
Чтобы получать заявки с сайта, позже подключим Telegram-бота или сервис обработки форм.
Изображения/иллюстрации в портфолио сейчас собраны CSS-элементами, внешние фотографии не нужны.
Google Fonts загружается из интернета; при отсутствии сети будет использован запасной системный шрифт.
